# Передача работы (25.11.2026)

Состояние на момент переезда сессии на сервер. Внутренние подробности (серверы, базы, записи секретницы) — в частной памяти проекта `workdesk-ai-pilot.md`, не в этом публичном репозитории.

## Сделано

- MCP-сервер `wdpilot`: 22 инструмента (17 действий как в `computer_toolset_20260801` + выбор окна, статус).
- Согласие на окно — системный диалог, по умолчанию «Нет», поверх всех окон.
- Стоп: Ctrl+Alt+Q или мышь в левый верхний угол; повторная проверка стопа прямо перед нажатием.
- Запреты: менеджеры паролей, банки, сам Pilot и окно Claude (обязательные); ввод в окна входа/оплаты, поле пароля Win32, номера карт, токены.
- Список запретов пользователя (`blocked_targets`, `--block` / `--unblock` / `--blocklist`): видеть цель можно, клик по ней, по кнопке запуска или Enter при видимой цели — только после «Да» пользователя. Распознавание текста — встроенный OCR Windows с подготовкой изображения и нечётким сравнением.
- Ввод на Windows: вставка через буфер обмена без истории (буфер пользователя возвращается), иначе посимвольно через SendInput; сочетания клавиш не зависят от раскладки.
- CI: Windows x64, Linux x64 (+ e2e под Xvfb), macOS arm64 и x64 — зелёный.

## Проверено вживую (Windows 11)

Блокнот: согласие «Да»/«Нет», снимок окна, клики, zoom, ввод 82/82 символа, буфер восстановлен, Ctrl+S/Ctrl+W, стоп, журнал.
1С через RDP (тестовая база, только просмотр): навигация, поиск, прокрутка.
Список запретов: «Да» пропускает действие, «Нет» блокирует клик по строке с целью и Enter.
